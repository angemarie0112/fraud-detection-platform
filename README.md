# Intelligent Fraud Detection Platform

An end-to-end Machine Learning application for detecting
fraudulent financial transactions.

## Project Overview

This project aims to build a production-oriented fraud
detection system using Machine Learning, FastAPI, Docker,
PostgreSQL, and Vue.js.

The platform will analyze transaction data, predict
potential fraud, and provide insights through an
interactive dashboard.

## Technology Stack

- Python
- Pandas & NumPy
- Scikit-learn
- XGBoost
- FastAPI
- PostgreSQL
- Docker & Docker Compose
- Vue 3
- MLflow
- AWS (planned deployment)
